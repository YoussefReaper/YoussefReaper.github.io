Command Center Guide

🚀 Getting Started

  • Click the + button to create your first mission
  • Create milestones to organize related tasks
  • Click on any task to view detailed analytics
  • Track your progress with the completion calendar
  • Switch between Control System and Modern System interfaces

🎨 Interface Modes

Control System - Sci-fi themed interface with advanced visual effects
Modern System - Clean, customizable interface that follows your theme preferences
Use the interface mode buttons at the top to switch between designs

⌨️ Keyboard Shortcuts

Ctrl + N - Create new task
Ctrl + M - Create new milestone
Esc - Close all modals
Ctrl + Shift + Del - Clear all data (⚠️ dangerous)

📱 Mobile Features

  • Swipe right on tasks to mark complete
  • Touch and hold for additional options
  • Fully responsive design for all screen sizes

🔄 Continuous Tasks & Reminders

  • Continuous Tasks - Create tasks that repeat automatically
  • Smart Reminders - Get notifications before tasks start
  • Late System - Tasks become late 2 hours after end time
  • Missed System - Tasks become missed 12 hours after end time
  • Daily Cycling - Completed tasks clear at midnight, new ones generate

🚦 Task Status System

🟢 Normal - Task is on time
🟡 Late - Task is overdue but can still be completed
🔴 About to Miss - Task will be missed soon if not completed
⚫ Missed - Task cannot be completed, breaks streak
🟡 Completed Late - Task was completed after deadline
